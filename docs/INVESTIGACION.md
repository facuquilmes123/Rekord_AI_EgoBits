# Investigación de MCP para Rekordbox y proyectos cercanos

Fecha de corte: 2026-09-23. Método: búsquedas web, consultas de API GitHub de repositorios, árboles, licencias y README, lectura de código seleccionado y paquete npm verificable. En `research/repos.tsv` hay **50 candidatos** (46 obtenidos, cuatro nombres supuestos que devolvieron error) y **10 adyacentes**; muchos son forks o espejos del mismo árbol. Es un inventario reproducible del rastreo, no una promesa de haber encontrado cada repositorio privado, desindexado o posterior a la fecha de corte. La búsqueda en el registro oficial de MCP no halló una entrada específica de Rekordbox en la consulta realizada; eso no prueba inexistencia universal. No se encontró un servidor MCP publicado por AlphaTheta en los canales oficiales revisados.

La fuente oficial de Rekordbox documenta la **entrada de playlists XML en Bridge**, y las FAQ documentan exportar la colección en XML: [rekordbox for Developers](https://rekordbox.com/en/support/developer/), [FAQ oficial](https://rekordbox.com/en/support/faq/operation-hints-7/). Esta superficie es más estable como primer puente que asumir una API general de control en vivo: no se encontró documentación pública de una API oficial general que conceda lectura de master deck y escritura de playlists nativas. Ese hallazgo es una limitación de documentación accesible, no una declaración absoluta sobre acuerdos privados o versiones futuras.

## Ecosistema que resuelve piezas distintas

- [dylanljones/pyrekordbox](https://github.com/dylanljones/pyrekordbox), MIT: lector de XML/base 6/7 y barrera en `commit()` cuando detecta Rekordbox en ejecución. Fuente de adaptadores de lectura, con validación de versión y concurrencia. La clave de cifrado, formatos internos y semántica de escritura podrían cambiar.
- Forks del servidor Dave: `jhiggins758/rekordbox-mcp` agrega variantes de cues/metadatos; `iltonandrew/rekordbox-mcp` trabaja MyTags; `kbooz/...` aborda USB. Otros nombres en el TSV comparten SHA de revisión o comparten el árbol y no representan diseños independientes. Evaluar cada cambio antes de integrar; no sumar funciones duplicadas para engordar el contador de tools.
- [chrisle/rekordbox-connect](https://github.com/chrisle/rekordbox-connect), MIT: cambios en base/historial para detectar actividad, útiles como indicios, **no prueba de master deck audible**. ## Riesgos concretos observados en código

1. En `upstream/davehenke__rekordbox-mcp/rekordbox_mcp/database.py`, `_create_backup()` maneja excepciones del backup y después pueden continuar operaciones de escritura. Diseñar un `BackupReceipt` con hash, verificación de restauración en copia y fallo cerrado. El software de escritura nativa debe habilitarse únicamente tras una matriz de versiones probadas.
2. En `upstream/interfluve-wav__rekordbox-smart-mcp/src/tools/setlist.ts`, la puntuación BPM/rating recibe el nombre de energía. En la UI mostrar fuente: `usuario`, `análisis_local`, `proxy_heurístico` o `sin_dato`. Una preferencia «subir energía real» no debe usar rating como si midiera audio.
3. La base SQL, historia y XML no contienen necesariamente el deck master, volumen del canal, crossfader o pista realmente audible. Se requiere sensor en vivo validado por equipo y versión y función automática desactivada si no hay fiabilidad suficiente.
4. La interfaz MCP es un contrato de tools, no una licencia para ejecutar todo lo que proponga un LLM; validación de argumentos, permisos por tool, confirmación de mutaciones, límites y vista previa. Ver [especificación MCP](https://modelcontextprotocol.io/specification/2025-06-18/server/tools).

## Procedencia

`research/repos.tsv` conserva repositorios, revisiones, licencia declarada por API, fechas y estado de descarga. `research/upstream_manifest.json` relaciona fragmentos MIT incluidos con su licencia en cada carpeta, URL de origen, commit y hash del archivo. El programa original de investigación inspeccionó otros archivos; la copia entregada es deliberadamente pequeña y revisable. La existencia de una licencia MIT a nivel de repositorio no certifica derechos sobre imágenes, marcas, música ni cualquier subdependencia.
